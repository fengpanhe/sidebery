# Chromium / Brave 功能说明

本文记录仓库中实验性 Chromium 版本已实现的标签管理能力。该版本是独立的 Manifest V3 扩展，代码位于 `chromium/`，面向 Chrome、Brave 等支持扩展侧边栏 API 的浏览器；它不是 Firefox 版本的完整功能移植。

## 侧边栏与窗口

- 在支持 `chrome.sidePanel` 的浏览器中，点击扩展图标或按 `Alt+Shift+S` 打开当前窗口的原生侧边栏。
- 某些 Chromium 衍生浏览器没有开放侧边栏 API 时，扩展会用独立的管理窗口显示当前浏览器窗口的标签，而不会影响网页本身。
- 标签列表只显示当前窗口。顶部标题栏和搜索框已移除，让空间留给标签树。
- “新建标签页”右侧提供“折叠其他标签树”按钮：点击后折叠除当前活动标签所在树以外的所有根树，当前树保持原状。
- 底部“新建标签页”按钮跟随列表流式排列，始终位于最后一个标签之后。

## 标签树与新标签规则

侧边栏用扩展自己的会话元数据维护父子关系；浏览器原生横向标签栏仍按浏览器的普通标签顺序显示。

| 场景                                                     | 结果                                           |
| -------------------------------------------------------- | ---------------------------------------------- |
| 在侧边栏选择“新建子标签”                                 | 新标签成为所选标签的直接子标签。               |
| 在侧边栏复制标签                                         | 复制出的标签成为原标签的直接子标签。           |
| 浏览器提供 `openerTabId` 的新标签                        | 成为来源标签的直接子标签。                     |
| 从系统、IM、其他应用或外部链接唤起，且没有 `openerTabId` | 不继承当前活动标签，作为根标签移动到列表末尾。 |
| 拖到目标标签中间                                         | 被拖拽标签及其后代成为目标标签的子树。         |
| 拖到目标标签上沿或下沿                                   | 保持同级并调整到目标分支之前或之后。           |

每一层标签使用更大的缩进，子标签图标位于父标签图标之后。带子标签的行在鼠标悬停或键盘焦点进入图标时才显示折叠箭头，避免常态界面拥挤。

父标签折叠后，子孙标签总数会作为徽标覆盖在父标签图标上。鼠标移到图标时徽标暂时隐藏并显示折叠箭头。

折叠状态会在切换到后代时自动展开祖先。关闭折叠的父标签时，扩展会关闭整个折叠分支；即使关闭操作来自浏览器原生标签栏，也会同步关闭其后代，避免留下孤立子标签。

## 标签操作

单击标签会激活它并聚焦对应浏览器窗口。中键、标签行右侧的关闭按钮或右键菜单都可以关闭标签。

右键菜单按“创建 / 复制与移动 / 状态 / 分组 / 关闭”分段，提供以下操作：

- 新建子标签；
- 复制当前标签；
- 将当前标签移到新窗口，或移到一个已有浏览器窗口。子菜单会列出目标窗口的活动标签标题及标签数量；
- 固定或取消固定；
- 静音或取消静音；
- 休眠非活动标签；
- 创建原生标签组、编辑分组，或移出分组；
- 关闭标签。

移动到其他窗口时只移动当前标签，不会把它的整棵子树一起移动。为了保持两边的树结构有效，原标签的直接子标签会回挂到原标签的父级；若原标签是根标签，这些子标签会成为根标签。

## 多选、原生分组与拖拽

- `Ctrl` / `⌘` 点击可逐个多选；`Shift` 点击可按列表顺序连续选择。
- 多选后可创建一个 Chromium 原生标签组，颜色、标题与浏览器原生分组同步。
- 分组标题使用彩色胶囊样式，可折叠浏览器原生分组。
- 拖拽会移动完整的树分支，并校验循环引用、跨窗口、固定标签和原生分组边界，防止产生无效层级。
- 拖动多选标签到另一个标签中间时，所有被选中的标签会按原有顺序移动，并分别成为目标标签的直接子标签；未选中的后代会跟随各自所属分支一起移动。

## 外观与可访问性

- 默认主题采用参考图中的浅薄荷背景（`#EFFFFD`）、灰青文字和青绿色选中态，另提供深色主题和紧凑、标准、宽松三种密度。
- 标签字体增大，行高与间距保持紧凑；当前标签以白色背景突出显示。
- 外观设置支持自定义 CSS，并会即时应用到已打开的侧边栏。
- 标签行支持方向键移动焦点，`Enter` 打开，`Delete` 关闭，`Escape` 关闭菜单或取消选择。

## 快照与状态保存

扩展可在后台保存当前窗口的标签、原生分组、树关系和折叠状态，恢复时会创建一个新窗口。快照最多保存 20 份，并会校验网址与数据结构，避免恢复危险或损坏的数据。

树形关系保存在扩展会话存储中：关闭再打开侧边栏可继续使用，但完全退出浏览器或在扩展管理页重新加载扩展后不会自动恢复。需要长期保留树关系时应使用快照。当前极简侧边栏没有暴露快照入口，相关能力保留在后台实现中。

## 不在当前范围内的能力

Firefox 版本中的容器、代理切换、隐藏浏览器原生标签栏、Firefox Sync、多面板工作区、Firefox 版设置和快照导入尚未移植。Chrome 与 Brave 的侧边栏位置和宽度由浏览器管理，扩展无法强制调整。

## 构建与验证

```sh
npm run test.chromium
npm run build.chromium.zip
```

测试覆盖树规范化、分支拖拽和关闭、外部链接置尾、标签复制、跨窗口移动、快照恢复、侧边栏菜单和样式行为。构建后的可加载目录位于 `dist/chromium/`，可分发 ZIP 位于 `dist/sidebery-chromium-0.1.0.zip`。安装步骤见 [Chromium 版本说明](chromium.md)。
