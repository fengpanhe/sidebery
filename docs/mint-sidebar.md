# 薄荷色侧边栏

浅色侧边栏使用浅薄荷背景（`#f0fffd`）、灰绿色文字（`#607e7d`）和青绿色活动标签（`#afdedd`），移除普通标签的卡片阴影，使用 8px 圆角。休眠标签保留淡化效果，但提高文字可读性。

## 在已安装的 Sidebery 中使用

1. 在 Sidebery 设置的外观中，将配色方案切换到「浅色 / Light」。
2. 打开「样式编辑器 / Styles editor」，选择「侧边栏 / Sidebar」。先备份已有的自定义 CSS。
3. 将 [theme.mint.css](../src/styles/sidebar/theme.mint.css) 的完整内容粘贴到编辑器末尾。编辑器会自动保存并应用。

删除所粘贴的这段 CSS，即可撤销自定义样式。如果原有样式使用了 `!important` 或更高优先级的选择器，可能需要先移除冲突的配色规则。

## 从源码使用

此 CSS 已由侧边栏样式入口引用，执行 `npm run build` 后随扩展构建生效。已安装的扩展不会因修改源码而自动更新；可以使用上面的样式编辑器方式立即应用。

配色按侧边栏各区域的浅色状态生效；深色区域不应用此覆盖。树形缩进、分组/容器颜色、标签行高和交互逻辑保持原有设置。这里只调整配色和表面样式，不会把 Sidebery 的分组结构转换为参考图中另一种分组布局。
