Sidebery

Chromium 版 · 外观设置

会应用到每个已打开的侧边栏。此版本的选择器与 Firefox 版有所不同，可使用下列变量调整配色。

:root {
  --frame-bg: #f1fffe;
  --frame-fg: #172326;
  --active-bg: #f7fafb;
  --row-height: 34px;
}

设置和快照仅保存在本机。Firefox 容器、代理规则、同步和隐藏顶部标签栏未移植到此版本。

快捷键可在浏览器的扩展快捷键页面修改。默认 Alt + Shift + S 打开侧边栏。
